# Portfolio V2

Personal portfolio for Shams Alqadri, built with React, JavaScript, and Vite.

## Run it locally

```bash
npm install
npm run dev
```

Vite prints a local address, usually http://localhost:5173. Open that in your browser.

## Folder guide

- `src/components` — reusable pieces such as the navbar, hero, and logo
- `src/pages` — one file per page: Home, Projects, and About
- `src/styles/global.css` — shared colors, fonts, and the paper background
- `src/data/projects.js` — project text and image paths (filled in the next step)
- `public/images` — logo, portrait, and paper texture

To swap a picture later, replace the file in `public/images` or change the path in the component.
